## 最新交互：先出参考结果，再逐步纠错

上传并完成识别后，价格表直接显示在原图上方，所有有价候选按每格价值或总价从低到高排序，不要求先勾选确认。顶部显示候选参考合计，含待核对/未分区项目，不含排除项、缺价和未录入物品；全部缺价时显示“未定价”，不是 0。整枪会标注“枪体参考价 · 不含完整配件”，不能据此判断整枪便宜。

漏项：点击“框选补一项”，拖动圈出一件物品（包含名称）；程序自动进行本地四方向裁剪重识别。选候选或搜索正确名称，检查所在区域、数量、占格，然后点“保存并更新参考价”。无需勾选确认即可先保存草稿。若替代错误框，请将原项排除，避免重复计价；可在“已排除”列表恢复。

认错：点击表格“纠错”，选择正确物品并保存，参考排名立即更新。当前仍会漏检，尤其是小字、合并标签、截断和遮挡；框选是补救入口，并不代表自动识别准确率已经提升。未经核对的最低参考价不等于安全丢弃建议。

## 使用流程

1. 上传 PNG/JPEG，默认“全图自适应”。不要求固定背包位置；支持边长 240–4096 像素、最多 1200 万像素、文件不超过 15 MB。清晰的原图最有利于识别。
2. 等待后台识别。编号只是候选：点击编号或表格“核对”，查看截图裁剪、目录图片、OCR 原文和候选名称。
3. 搜索正确物品，选择所在区域，修正数量和实际占格。价格缺失可填写核实过的手工单价或整堆总价。
4. 框选不准/遗漏：选择“框选补一项”并拖动圈出正确区域，会自动尝试四个旋转方向的 OCR/图标特征候选；也可直接搜索。它不会自动改名或确认。如果新框替代旧错误框，务必把旧项标为排除，避免重复计价。
5. 保存即可更新参考价；全部核实后再勾选核对确认。错误/重复项可排除，需要保留的物品可锁定。确认表明用户核对过字段，不意味着价格实时或模型已证明正确。
6. 切换“总价最低”或“每格价值最低”比较。待处理项不进入已核对排名；确认当前范围无遗漏，且不存在缺价/未知数量/配置缺口后，才显示完整的当前范围参考排名。过期快照需明确接受后才能完成这一步。

“全图自适应”使用全图 OCR 文本位置和名称候选，不使用固定背包坐标；根据标题尝试推断区域，不能推断时标记“所在区域待选择”。物品框大小仍是根据目录尺寸的近似候选，旋转武器、皮肤、遮挡或截断都可能使它不准，必须核对。仅裁剪重识别会尝试四个 90° 方向；没有实现任意透视角度、无文字图标或隐藏物品的可靠全自动检测。

## 武器配件怎么处理

散放且可见的配件可作为独立物品识别、搜索和估价。整枪缩略图无法可靠给出所有已装配配件的具体型号；候选参考列表可先显示枪体目录价，但会注明不含完整配件，不作为已核对完整枪价。

第一阶段：填写你核实过的“当前整件/整堆总价”，包含枪体、配件、弹匣和实际装填弹药。这个数直接作为总价，不再乘数量，也不叠加目录价。没有核实总价就保持待处理。

下一阶段：上传能看清配件名称/槽位的枪械详情图，将配件逐项关联到同一把枪，再生成带来源的分项清单。此项尚未实现；不要误以为四方向裁剪识别能推断隐藏配件。

## 价格和纠错数据

- 原库 `AppData/Local/DeltaLootAssistant/assistant.sqlite3` 通过 SQLite `mode=ro` 只读加载；不会导入演示价格代替真实数据，不提供同步按钮，不读取付费 Token。
- 本地快照被冻结在网页服务启动时。用桌面端手动更新过快照后，需重启网页服务才能加载新版本。
- 纠错记录单独存于 `AppData/Local/DeltaLootAssistant/web-review/corrections.sqlite3`，不修改原价格包。
- 默认只保存截图像素哈希、坐标、物品 ID、数量、价格修正、区域与核对记录，不保存完整图片。
- 仅明确勾选“保存已确认裁剪”时，把对应裁剪作为 BLOB 和标签写入纠错库。不是上传到第三方，也不是自动训练模型。
- 同一张图再次上传时可恢复已保存的纠错建议，但重新标记为未确认。截图位置或像素变化后不能保证复用同图记录。新图会替换当前内存预览；关闭服务后完整图片需要重新上传。

## 当前可信范围

仅对当前截图中已录入、已分区、已核对且价格口径完整的项目给出参考排名。缺价显示“未定价”，不当作 0；用户显式填写 0 则是一项可追溯的手工判断。弹药按确认发数乘单价；武器、护甲、头盔、消耗品和钥匙等配置/耐久/剩余次数相关物品保守要求当前总价。

“已核对参考合计”只统计已核对项，不代表完整背包总价。锁定项仍参与价格比较，但不是替换候选。没有做全局装箱、自动拖动或最低操作时间优化。

## 本地服务安全与文件说明

- `src/delta_loot_assistant/web_server.py`：仅监听 127.0.0.1，检查 Host/Origin 与每次运行随机生成的同源请求校验值；限制上传大小，无任意文件读取或付费 API 路由。
- `web_review.py`：只读快照、后台扫描会话、人工纠错、单独纠错库及可信排名阻断条件。
- `adaptive_recognition.py`：全图 OCR 候选与文字位置关联、标题区域提示、性能浮层过滤及武器短名称优先匹配。
- `web_assets/index.html`、`app.css`、`app.js`：上传/截图标注/纠错/表格界面，全部资源来自本机，无外部字体、CDN 或统计脚本。
- `tests/test_web_review.py`：估价、缺价、枪价、重复计价、纠错持久化、跨源防护、尺寸和位置变化等回归测试。
- 浏览器支持时提供只读的当前核对排名 WebMCP 工具；未在支持 WebMCP 的真实浏览器环境中验收，不影响普通网页使用。

这是个人本机工具，不要改成监听 0.0.0.0 或直接暴露到公网。公开上线需要独立的认证、数据隔离、素材授权、存储和 Python OCR 部署方案；本轮没有发布云端。
